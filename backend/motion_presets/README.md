# Bundled premade motion presets

This directory is the read-only, version-controlled library of premade motion clips.

- Add only reviewed/approved NPZ presets here.
- An optional thumbnail may use the same basename with .png or .webp.
- The API exposes these bundled files through GET /api/v1/motion/presets.
- Do not place user uploads or generated user clips here. They belong under backend/storage/presets/<preset_id>/.
- Do not add synthetic/example clips and present them as real ARDY output.

The directory is intentionally empty until real premade clips are supplied.
