## 2026-11-14 — Batch 5 Frontend Workspace & Generation Flow Integration

- **Frontend State Store Alignment (`WorkspaceContext.tsx`, `useViewerStore.ts`, `useAppStore.ts`):** Modeled explicit `executionState` (`idle`, `queued`, `running`, `completed`, `failed`, `interrupted`) and `persistenceState` (`not_saved`, `saving`, `saved`, `save_failed`, `discarded`) with state transition validation guards.
- **Backend `workspace_id` Route Alignment:** Replaced client-side ephemeral route hashing (`routeShortId`) with authoritative backend `workspace_id` (`/workspace/generate/<workspace_id>`). Decoupled asset selection in the Assets panel so choosing an asset updates only `active_mesh_asset_id` on the workspace state without mutating or replacing the URL route.
- **Dynamic Mesh Versions Selector (`ViewportToolOverlay.tsx`):** Added dynamic versions dropdown control hidden when workspace contains only its raw base mesh; dynamically visible once derived assets exist (`_v002`, `_v003`), allowing direct in-viewport switching between versions.
- **Stale Viewer Fetch Race Protection (`MeshViewer.tsx`, `glbCache.ts`):** Integrated `AbortController` into 3D viewer model loading so in-flight requests from prior asset selections are cleanly aborted, preventing race-condition viewport overwrites.
- **Dockable Operation Action Bar (`OperationActionBar.tsx`):** Integrated studio action bar for active derived previews with three explicit actions: "Keep in Workspace" (permanently retains preview asset and transitions to `saved`), "Regenerate" (creates new linked attempt with `parent_operation_id`), and "Discard Preview" (purges temporary output and restores base mesh).
- **Consolidated Adaptive Poller (`hooks/useTaskPolling.ts` & `hooks/useTaskManager.ts`):** Consolidated duplicate background polling loops into a single adaptive scheduler: 1.5s initial cadence, 5s backoff after 2 minutes of active tasks, automated pause when tab is hidden (`visibilitychange`), and clean termination when all tasks reach terminal state.
- **Global Workspaces Gallery (`StudioDashboard.tsx`):** Added interactive workspaces card gallery on the studio dashboard, displaying asset counts and metadata, navigating directly to `/workspace/generate/<workspace_id>`.
- **Thumbnail Resilience (`RightAssetsPanel.tsx`):** Added `onError` fallback handling so broken or missing thumbnails gracefully display styled geometric placeholders. Added workspace scope toggle between workspace-only and global asset library.
- **Direct Model-Native Default:** Enforced direct model-native neural mesh output as standard default (`enablePostprocess: false`), removing prominent post-processing claims.
