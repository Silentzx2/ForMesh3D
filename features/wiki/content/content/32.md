# Auto Rigging

Open **Workspace → Rigging** at `/workspace/rigging` and select the character mesh to rig.

## SkinTokens AI

The active auto-rigging action submits the mesh to the SkinTokens backend and returns a skinned GLB when successful. The current adapter uses its learned unified autoregressive representation with transfer post-processing for scale and texture preservation. Custom skeleton presets, IK generation and arbitrary weight overrides are not supported by this adapter.

Advanced controls should be treated as effective only where the active backend contract accepts them. Check the resulting job state and confirm that the output includes a skeleton and skin weights before sending the asset into animation or export.

## Manual armature

The panel distinguishes the Manual Armature path from SkinTokens AI. Selecting Manual Armature does not run the SkinTokens inference request; the manual route is a separate editing workflow. Do not interpret a mode change alone as a generated rig.
